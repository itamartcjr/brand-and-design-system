# Slider

**ID:** `slider`  
**Grupo:** Actions & Controls

## Obrigatório

Single/range quando aplicável, track, thumb, value display, marks, disabled, focus, teclado, min/max/step e touch target.

## Prompt da página

```text
Gere a página Slider mantendo a shell estrutural idêntica à referência. Documente o slider real do projeto: single ou range, track, thumb, marks, value display, min/max/step, Default/Hover/Focus/Active/Disabled. Demonstre mouse, touch e teclado. Mostre hit area, tokens e comportamento responsivo. Se o projeto não usa slider, sinalize como não aplicável em vez de inventar um componente desnecessário.
```
