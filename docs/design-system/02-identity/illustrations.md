# Illustrations

**ID:** `illustrations`  
**Grupo:** Identity

## O que a página precisa ensinar

A linguagem ilustrativa usada em produto, empty states e conteúdos de apoio.

## Obrigatório

- estilo, forma, stroke/fill, cor e proporção;
- tamanhos e contextos;
- exemplos positivos e negativos;
- composição com componentes reais;
- acessibilidade/decorative semantics;
- fonte/licença dos assets.

## Prompt da página

```text
Gere a página Illustrations na shell estrutural idêntica à referência. Audite ilustrações reais do projeto e documente estilo, construção, cores, proporções, tamanhos e aplicações. Mostre This is us / This isn't us quando houver critérios suficientes. Diferencie imagem informativa de decorativa para acessibilidade. Não invente uma linguagem ilustrativa nova se o projeto já possui uma.
```
