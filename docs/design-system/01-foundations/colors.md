# Colours

**ID:** `colors`  
**Grupo:** Foundations

## O que a página precisa ensinar

Primitive colors e semantic colors para brand, neutral, surface, text, border, action e feedback.

## Obrigatório

- paleta visual completa;
- primitive → semantic mapping;
- light/dark quando houver;
- contraste relevante;
- estados de ação;
- sucesso, warning, error e info;
- tokens usados em exemplos reais.

## Prompt da página

```text
Gere a página Colours mantendo a shell estrutural idêntica à referência. Extraia as cores reais do projeto e organize em primitive tokens, semantic tokens e, se necessário, component tokens. Mostre swatches, nomes, valores, papéis e relações. Inclua text/background, surface, border, action e feedback; documente light/dark se existir. Valide contraste e mostre pares aprovados. Não copie a paleta de exemplo do projeto de referência.
```
