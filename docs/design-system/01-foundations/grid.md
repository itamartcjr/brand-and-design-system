# Layout Grid

**ID:** `grid`  
**Grupo:** Foundations

## O que a página precisa ensinar

Como o projeto organiza viewport, container, colunas, gutters e margens em Desktop, Tablet e Mobile.

## Obrigatório na página

- viewport desenhada em escala visual;
- colunas realmente visíveis, não apenas descritas;
- medidas de margin, gutter, container e column width;
- breakpoints e comportamento entre eles;
- exemplo real com conteúdo sobre o grid;
- tokens do projeto de destino;
- comparação Desktop → Tablet → Mobile.

## Critério de aceite

A pessoa deve entender o grid apenas olhando a demonstração. Nenhum número de exemplo da referência deve ser usado sem validação no projeto de destino.

## Prompt da página

```text
Gere a página Layout Grid dentro da shell estrutural idêntica ao projeto de referência. Preserve sidebar, posição da marca/logo, busca, topbar, ações e área de conteúdo. Audite o grid real deste projeto e documente Desktop, Tablet e Mobile visualmente: viewport, colunas, margens, gutters, container, largura útil, breakpoints e comportamento intermediário. Sobreponha as colunas a um exemplo real de interface. Exiba os nomes dos tokens e seus valores efetivos. Não copie 12/8/4 colunas ou medidas da referência sem confirmar que são as decisões deste projeto. Inclua regras de uso, Do/Don't e critérios responsivos.
```
