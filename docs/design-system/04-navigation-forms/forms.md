# Forms

**ID:** `forms`  
**Grupo:** Navigation & Forms

## Obrigatório

Input, search, password, textarea, select e demais campos reais; labels, placeholder, helper, error/success, required/optional, disabled, readonly, autofill e validação.

## Prompt da página

```text
Gere a página Forms mantendo a shell estrutural idêntica à referência. Audite os campos realmente usados no produto e documente anatomia, labels, placeholder, helper text, ícones e estados Default/Hover/Focus/Typing/Filled/Error/Success/Disabled/Readonly quando aplicáveis. Mostre formulários completos, não apenas campos isolados. Documente validação, mensagens, keyboard type/autocomplete quando relevante, acessibilidade e tokens. Preserve componentes existentes e elimine valores mágicos apenas quando houver migração segura para tokens.
```
