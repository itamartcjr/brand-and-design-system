# Tabs

**ID:** `tabs`  
**Grupo:** Navigation & Forms

## Obrigatório

Anatomia, active indicator, Default/Hover/Focus/Active/Disabled, teclado, overflow/scroll e relação tabs ↔ panels.

## Prompt da página

```text
Gere a página Tabs mantendo a shell estrutural idêntica à referência. Reuse o padrão real do produto e documente anatomia, variantes, estados, indicador ativo, overflow e comportamento responsivo. Implemente semântica tablist/tab/tabpanel quando apropriada e navegação por teclado consistente. Exiba tokens de spacing, height, indicator, color e motion. Não use tabs para navegação que semanticamente deveria ser links.
```
