# 08 — Visual Brand Identity

**Fonte de verdade:** `src/brand/modules/catalog.js` (`visual-brand-identity`).

## Filhos obrigatórios

Primary Logo; Secondary Logo; Symbol; Wordmark; Logo variations; Positive; Negative; Monochrome; Clear Space; Minimum Size; Background Usage; Incorrect Usage; Co-branding; Logo Decision Tree; Brand Colors; Primary Colors; Secondary Colors; Neutral Colors; Supporting Colors.

## Como executar todos os filhos

Use somente assets oficiais. Mostre cada assinatura em contexto, medidas, clear space, limites e fundos. Crie decision tree para escolha de versão. Cores aqui são de identidade de marca; tokens funcionais de interface pertencem ao Design System.

## Prompt master do módulo

```text
Execute Visual Brand Identity inteira, gerando uma página por field. Use os assets reais da marca. Documente logo principal/secundário, símbolo, wordmark e variações com exemplos positivos/negativos/mono, clear space, tamanho mínimo, fundos e usos incorretos. Em co-branding, mostre hierarquia e espaçamentos. Construa um Logo Decision Tree funcional. Para cores, mostre papel, proporção e aplicações de Primary/Secondary/Neutral/Supporting sem confundir Brand Colors com semantic UI tokens. A documentação deve ser altamente visual e mensurável.
```
