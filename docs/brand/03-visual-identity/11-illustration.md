# 11 — Illustration

**Fonte de verdade:** `src/brand/modules/catalog.js` (`illustration`).

## Filhos obrigatórios

Estilo; Formas; Traços; Proporções; Perspectiva; Personagens; Cores; Texturas; Sombras; Fundos; Composição; This is us; This isn't us; Licenciamento.

## Como executar todos os filhos

Documente a receita visual de modo reproduzível. Separe princípios invariáveis de variações permitidas. Mostre exemplos e contraexemplos e origem/licença dos assets.

## Prompt master do módulo

```text
Execute Illustration inteira, uma página por field. Construa uma receita visual objetiva para estilo, formas, traços, proporções, perspectiva, personagens, cores, texturas, sombras, fundos e composição. Use diagramas de construção e exemplos reais. Crie This is us / This isn't us com razões específicas. Diferencie decisões obrigatórias de liberdade criativa. Registre licenciamento e ownership. O conjunto final deve permitir que outro ilustrador produza algo reconhecível como a marca sem copiar uma peça existente.
```
