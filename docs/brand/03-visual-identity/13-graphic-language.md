# 13 — Graphic Language

**Fonte de verdade:** `src/brand/modules/catalog.js` (`graphic-language`).

## Filhos obrigatórios

Shapes; Patterns; Frames; Lines; Textures; Gradients; Masks; Containers; Graphic devices; Decorative elements; Brand signatures; Reconhecimento sem logo.

## Como executar todos os filhos

Crie um sistema de dispositivos proprietários, não uma coleção de efeitos soltos. Cada elemento deve mostrar construção, variações, proporção de uso e combinações permitidas.

## Prompt master do módulo

```text
Execute Graphic Language inteira, uma página por field. Documente shapes, patterns, frames, lines, textures, gradients, masks, containers, graphic devices, decorative elements e signatures como um sistema combinável. Mostre regras de construção, escalas, composições e excessos a evitar. Termine com testes de Reconhecimento sem logo: aplicações nas quais a marca ainda seja identificável apenas pela linguagem gráfica.
```
