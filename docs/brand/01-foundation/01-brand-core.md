# 01 — Brand Core

**Fonte de verdade:** `src/brand/modules/01-core.js`

## Objetivo

Definir o núcleo que deve permanecer verdadeiro quando produtos, campanhas e canais mudam.

## Filhos obrigatórios

Brand Essence; Purpose; Mission; Vision; Values; Brand Promise; Positioning; Value Proposition; Differentiators; Audience; Personas; Needs; Pain Points; Brand Story; Manifesto; Ambition; Brand Beliefs; Brand Principles.

## Como executar todos os filhos

Execute na ordem da fonte. Para cada item, aplique `docs/brand/PAGE-SPEC.md` e crie uma página completa. Sempre conecte a decisão a evidência ou marque-a como hipótese. Depois faça revisão cruzada: Purpose ≠ Mission ≠ Vision; Promise precisa ser sustentável; Positioning precisa conectar público, categoria, diferença e prova; Values/Beliefs/Principles precisam mudar comportamento real.

## Prompt master do módulo

```text
Execute o módulo 01 — Brand Core inteiro. Leia `src/brand/modules/01-core.js` e gere uma página para cada field, na ordem, sem exceções. Use PAGE-SPEC.md como contrato. Não aceite frases genéricas: cada decisão deve ser específica, defensável e útil como filtro. Mostre Essence, Purpose, Mission e Vision lado a lado para eliminar sobreposição; transforme Values, Beliefs e Principles em comportamentos observáveis; conecte Promise, Positioning, Value Proposition e Differentiators a evidências; trate Audience/Personas/Needs/Pain Points como entradas baseadas em pesquisa. Finalize com mapa visual de dependências e uma checagem de contradições entre todos os itens.
```
